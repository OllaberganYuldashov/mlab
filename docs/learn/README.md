# docs/learn — egasi uchun darslar

Loyihaga har yangi texnologiya kirganda Claude shu papkaga alohida dars yozadi: `<texnologiya>.md`.
Har run oxirida `JOURNAL.md`ga qisqa yozuv qo'shiladi.

## Dars shabloni

```markdown
# <Texnologiya nomi>

## Bu nima (2–3 gap, oddiy tilda)
## Nega aynan u tanlandi (va muqobillari)
## Bizning loyihada qayerda ishlatilgan (fayl havolalari)
## Asosiy tushunchalar (3–7 ta)
## Rasmiy hujjat va yaxshi manbalar
## Kichik mashq (o'zingiz bajarib ko'rish uchun)
```
